# Week 6: Exercises - Dynamical Diffraction

Practice problems to reinforce concepts from Lecture 6.1 and the code examples.

## Exercise Set

### exercise_01_ewald_sphere_basics.ipynb
**Topics**: Ewald sphere, reciprocal lattice, Bragg condition
- Construct Ewald spheres for different electron wavelengths
- Identify reciprocal lattice points in diffraction
- Calculate excitation errors for various crystal orientations
- Predict how crystal tilting changes the diffraction pattern

### exercise_02_bloch_wave_analysis.ipynb
**Topics**: Bloch waves, channeling, symmetry
- Expand electron wavefunctions in Bloch basis
- Calculate band structure in 1D and 2D crystal potentials
- Identify channeling vs anti-channeling directions
- Analyze atomic column density in HAADF contrast

### exercise_03_thickness_fringes.ipynb
**Topics**: Two-beam dynamical theory, Pendellösung, extinction distance
- Calculate extinction distances for various reflections
- Predict fringe spacing for given thicknesses
- Simulate thickness fringe patterns
- Interpret fringes in experimental HRTEM images

### exercise_04_dynamical_vs_kinematic.ipynb
**Topics**: Comparison between kinematic and dynamical diffraction
- Compute diffraction intensities using kinematic approximation
- Compare with dynamical diffraction results
- Identify thickness regimes where kinematic theory fails
- Analyze phase contrast in HRTEM

## Difficulty Progression

1. **Beginner**: Ewald sphere construction and visualization
2. **Intermediate**: Bloch wave calculations and interpretation
3. **Advanced**: Full dynamical diffraction simulations
