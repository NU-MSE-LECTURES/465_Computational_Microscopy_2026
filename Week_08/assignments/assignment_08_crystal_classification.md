# Assignment 8: AI-based Crystallographic Classification

## Goal
Build a small and interpretable pipeline that groups diffraction patterns by structure-like features and then labels them with a simple classifier or template matcher.

## Tasks
1. Start from `code_examples/example_01_diffraction_feature_clustering.py` and generate at least three synthetic pattern families.
2. Extract radial or angular features and visualize the first two PCA components.
3. Use either k-means or a nearest-template classifier to assign labels.
4. Report one failure mode and one improvement you would make for real diffraction data.

## Deliverables
- one figure showing representative patterns
- one figure showing the feature-space embedding
- a short write-up describing the chosen features and the observed limitations
