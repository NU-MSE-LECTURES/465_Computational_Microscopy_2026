# Assignment 9: Integrated Analysis Pipeline

## Goal
Create a reproducible microscopy workflow that combines at least three analysis steps and evaluates one tradeoff between runtime and output quality.

## Required components
1. one synthetic or experimental input image
2. one preprocessing step
3. one segmentation or feature-extraction step
4. one summarized output table or figure
5. one short benchmark comparing at least two parameter settings

## Deliverables
- a single runnable script or notebook
- one runtime comparison plot or table
- a short note on how the workflow would need to change for larger datasets or cluster execution
