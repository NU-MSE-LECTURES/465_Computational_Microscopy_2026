# Week 10: Final Projects and Future Trends
March 9-13, 2026

## Overview
The final week is organized around project execution and communication. The example files are intentionally lightweight and are meant to help students scope a final project, track milestones, and present quantitative results clearly.

## Monday: Final Project Presentations I
- Computational project presentations by students
- Peer feedback and scientific discussion

## Wednesday: Final Project Presentations II and Course Reflection
- Continued student presentations
- Discussion on autonomous and closed-loop microscopy
- Future research directions and professional pathways

## Final Project Due
Technical report, GitHub repository, and oral presentation

## Code Examples
- **example_01_project_timeline_and_scope.py**: define project milestones and render a simple Gantt-style schedule
- **example_02_results_summary_dashboard.py**: build a compact dashboard for accuracy, runtime, and error analysis figures

## Deliverables
- A short technical report with methods, figures, and limitations
- A clean repository with runnable code and documented dependencies
- A final presentation with one main scientific question and one validated computational result

## Resources
- Project checklist and presentation guidance are included in `assignments/final_project_checklist.md` and `resources/resources.md`
